# Vippi Leads

Vippi Leads — B2B SaaS для AI-контроля обработки заявок для застройщиков и агентств недвижимости Ташкента. Сервис помогает отслеживать, насколько быстро и качественно отдел продаж реагирует на входящие заявки. Текущая цель — демо-MVP.
