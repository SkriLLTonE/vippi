# Дизайн-система: Vippi Leads — демо-MVP

**Версия:** 1.0 · **Дата:** 2026-10-21 · **Статус:** PROPOSED
**Основа:** shadcn/ui + Radix + Tailwind CSS 4 (ADR-007). Токены задаются CSS-переменными в `apps/web/src/app/styles/tokens.css` и подключаются в тему Tailwind/shadcn.
**Связанные документы:** [UX-UI-spec](./UX-UI-spec.md) · [SPEC](../technical/SPEC.md)

---

## 1. Визуальная концепция

- **Характер:** спокойный профессиональный B2B-инструмент для ежедневной работы: много воздуха, нейтральная серо-синяя палитра, **один акцентный цвет** (индиго) для основных действий и фокуса.
- **Цвет несёт смысл:** красный — только просрочка и разрушительные действия; янтарный — «скоро просрочка» и демо-баннер; зелёный — «ответ вовремя» и сделка. Акцент не используется для статусов.
- **Плотность:** базовый текст 14 px, строки таблицы 44 px — РОП видит 15+ лидов на экране 1080p.
- **Цифры:** табличные цифры (`font-variant-numeric: tabular-nums`) для таймеров, KPI, сумм.
- **Тема:** только светлая в MVP; токены сделаны семантическими, чтобы тёмную тему можно было добавить без правки компонентов.

## 3. Типографика

- **Шрифт:** Inter (variable), самостоятельный хостинг через пакет `@fontsource-variable/inter` (CSP `default-src 'self'`, без внешних CDN). Нужные наборы: Latin, Latin Extended, Cyrillic.
- **Узбекская латиница:** символы `oʻ gʻ` используют U+02BB, tutuq belgisi — U+02BC. **TBD при установке:** проверить наличие глифов U+02BB/U+02BC в подключённом наборе Inter на тестовой строке «Oʻzbekiston, gʻoya, maʼlumot, Mirzo Ulugʻbek»; если глифа нет, браузер подставит fallback, поэтому в стеке есть **Noto Sans** (тоже self-hosted, `@fontsource/noto-sans`, только при необходимости).
- **Стек:** `"Inter Variable", "Noto Sans", system-ui, -apple-system, "Segoe UI", Roboto, Arial, sans-serif`.
- **Моноширинный** (API-ключи, curl-пример): `ui-monospace, "SFMono-Regular", Consolas, monospace`.

| Токен | Размер / межстрочный | Насыщенность | Применение |
|---|---|---|---|
| `text-xs` | 12 / 16 | 500 | Метки, подписи осей, бейджи |
| `text-sm` | 14 / 20 | 400 | Основной текст, таблицы, поля |
| `text-base` | 16 / 24 | 400 | Текст обращения в карточке, поля на мобильном (против авто-зума iOS) |
| `text-lg` | 18 / 28 | 600 | Заголовки карточек и диалогов |
| `text-xl` | 20 / 28 | 600 | Заголовок страницы (мобильный) |
| `text-2xl` | 24 / 32 | 600 | Заголовок страницы (десктоп) |
| `text-3xl` | 30 / 36 | 600 | Значение KPI |

Правила: не более 3 размеров на экране кроме KPI; полужирный (600) — только заголовки и критичные значения; КАПС не используется.

## 4. Отступы, сетка, радиусы, тени

- **Отступы:** шаг 4 px — `1`=4, `2`=8, `3`=12, `4`=16, `5`=20, `6`=24, `8`=32, `10`=40, `12`=48, `16`=64. Внутренний отступ карточки — 24 (десктоп) / 16 (мобильный); между секциями страницы — 32; между полями формы — 16.
- **Сетка:** контент страницы — max-width 1440 px, поля 24 px (десктоп) / 16 px (мобильный); KPI — 4 колонки (`xl`), 2 (`md`), 1 (`sm`).
- **Радиусы:** `--radius-sm` 4 px (бейджи, чипы), `--radius-md` 6 px (кнопки, поля), `--radius-lg` 8 px (карточки, таблицы), `--radius-xl` 12 px (диалоги, листы), `full` (аватары, точки).
- **Тени:** `shadow-xs` `0 1px 2px rgb(15 23 42 / 0.05)` — поля, кнопки secondary; `shadow-sm` `0 1px 3px rgb(15 23 42 / 0.08)` — карточки; `shadow-md` `0 4px 12px rgb(15 23 42 / 0.10)` — поповеры, меню; `shadow-lg` `0 12px 32px rgb(15 23 42 / 0.16)` — диалоги.
- **Движение:** 150 мс (наведение, бейджи), 200 мс (поповеры, диалоги), easing `cubic-bezier(0.2, 0, 0, 1)`; отключается при `prefers-reduced-motion`.
- **Слои (z-index):** сайдбар 30, топбар 40, поповер/меню 50, диалог 60, toast 70.

## 5. Правила компонентов (сопоставление с shadcn/ui)

| Компонент | shadcn/ui | Правила |
|---|---|---|
| Кнопка | `Button` | Варианты: `default` (primary) — одно основное действие на область; `secondary`, `outline`, `ghost` — второстепенные; `destructive` — только в подтверждениях удаления/деактивации/отзыва; `link`. Размеры `sm` 32 px, `default` 36 px, `lg` 40 px, `icon` 36×36 (на мобильном — 44). Состояние загрузки: спиннер `Loader2` слева + текст «Сохранение…», `disabled`. Текст — глагол |
| Поля ввода | `Input`, `Textarea`, `Form` (+ React Hook Form) | Подпись над полем всегда (плейсхолдер — не подпись); подсказка под полем `text-xs --muted-foreground`; ошибка — `--danger` под полем, граница `--danger`; счётчик символов для ограниченных полей (комментарий, черновик). Телефон — подсказка формата `+998 __ ___ __ __` |
| Выбор | `Select`, `Combobox` (`Command` + `Popover`), `Checkbox`, `RadioGroup`, `Switch`, `ToggleGroup` | ≤7 вариантов — `RadioGroup`/`ToggleGroup` (канал контакта, язык, тон); больше — `Select`/`Combobox` с поиском (ответственный). `Switch` — только для немедленно применяемых настроек с подтверждением (AI-согласие) |
| Даты | `Calendar` + `Popover` (react-day-picker) | Пресеты периода рядом с календарём; неделя с понедельника; локаль `ru`/`uz` |
| Таблицы | `Table` + DataTable на TanStack Table | Заголовки `text-xs` 500 `--muted-foreground`; строка 44 px; наведение `--background-subtle`; вся строка кликабельна (+ ссылка в первой ячейке для клавиатуры); числовые колонки выровнены вправо, tabular-nums; сортировка — иконка + `aria-sort`; пагинация `Pagination` снизу (страница, размер, всего) |
| Карточки | `Card` | KPI-карточка (`KpiCard`): подпись `text-sm`, значение `text-3xl`, иконка `Info` с `Tooltip` «как считается»; кликабельные KPI имеют стрелку `ArrowUpRight` |
| Фильтры | `Badge`-чипы (`ToggleGroup`), `Popover` + `Command` для мультиселекта, `Input` поиска | Активный фильтр — чип с `--primary-subtle` и кнопкой «×»; «Сбросить» видна при ≥1 активном фильтре; поиск с задержкой 300 мс |
| Диалоги | `Dialog`, `Sheet` (мобильный/боковая панель) | Заголовок + краткое описание; основное действие справа; ширина 480 (форма) / 720 (импорт CSV); на `sm` — `Sheet` снизу на всю ширину |
| Подтверждения | `AlertDialog` (`ConfirmDialog`) | Заголовок-вопрос с объектом («Удалить лид #123?»), последствия одним абзацем, кнопки «Отмена» (фокус по умолчанию) и `destructive` с глаголом («Удалить», «Деактивировать», «Отозвать») |
| Меню | `DropdownMenu` | Действия строки и «…» в шапке; разрушительные пункты внизу, отделены `Separator`, красным текстом |
| Бейджи | `Badge` + варианты `status-*`, `sla-*`, `score-*`, `ai`, `rules`, `demo` | Высота 22 px, `text-xs`, иконка 14 px + текст; только цвета из §2.3–2.5 |
| Уведомления | `Popover` (десктоп) / `Sheet` (мобильный) + `ScrollArea` | Непрочитанные — точка `--primary` и фон `--primary-subtle` |
| Toast | `Sonner` | Справа снизу (десктоп) / сверху (мобильный); 4 с; успех — `CheckCircle2` `--success`; ошибка — `XCircle` `--danger`, 8 с, с действием «Повторить» при сетевых ошибках; не более 3 одновременно |
| Скелетоны | `Skeleton` | Повторяют геометрию контента; появляются через 200 мс задержки; без анимации при `prefers-reduced-motion` |
| Пустые состояния | Свой `EmptyState` (на `Card`) | Иконка Lucide 40 px `--subtle-foreground`, заголовок `text-lg`, описание ≤2 строк, 1 основное действие + опционально второстепенное |
| Ошибки | `Alert` (variant `destructive`) / свой `ErrorState` | Текст по коду ошибки + «Повторить»; для 403/404 — полноэкранные страницы с иконками `Lock` / `SearchX` |
| Демо-баннер | Свой `DemoBanner` на `Alert` | `--warning-bg`, текст `--warning`, иконка `FlaskConical`, высота 36 px, без закрытия |
| AI-панель | `Card` + `Tabs` (мобильный) + `Progress` (оценка) + `Textarea` (черновик) | Метка режима в шапке панели всегда видна; баннер «Проверьте перед отправкой» — `Alert` `--warning`; черновик в `Textarea` с авто-высотой и счётчиком 0/700 |
| Таймер SLA | Свой `SlaBadge` + `Countdown` | Обновление раз в 30 с; вычисление от `serverTime`-поправки; формат длительности через `shared/lib/format` |
| Графики | `Chart` (shadcn, Recharts) | Подписи осей `text-xs`; тултип с датой `ДД.ММ` и значениями; цвета §2.6 |
| Аватар | `Avatar` | Инициалы на `--primary-subtle`; в таблицах 24 px |
| Подсказки | `Tooltip` | Только для дополнительной информации; не прятать в тултип обязательные сведения; открытие по фокусу и наведению |

## 6. Иконки

Lucide, размер 16 px в тексте и кнопках, 20 px в навигации, 40 px в пустых состояниях; толщина линии 2 (по умолчанию). Источники лида: `Instagram`, `Send` (Telegram), `Globe` (сайт), `ShoppingBag` (OLX), `Phone`, `DoorOpen` (визит), `Users` (рекомендация), `CircleHelp` (другое). Иконки брендов используются только как пиктограммы канала, без логотипов.

## 7. Чек-лист реализации токенов
1. Токены §2–4 заданы CSS-переменными; компоненты shadcn используют только переменные (без «сырых» HEX в компонентах).
2. Контраст всех пар §2 проверен инструментом; результаты записаны в PR.
3. Глифы U+02BB/U+02BC проверены на тестовой строке (§3).
4. Скриншот-проверка ключевых экранов на `ru` и `uz` в 3 вьюпортах (NFR-011).
