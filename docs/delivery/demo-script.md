# Сценарий демо: Vippi Leads

**Длительность:** 12–15 минут · **Язык:** RU (с переключением на UZ в шаге 8) · **Режим AI:** rule-based (ключа Gemini нет — это честно видно в интерфейсе)
**Все данные синтетические** — организация «Demo Realty Toshkent (DEMO)», телефоны `+99800…`, баннер «Демо-данные» в интерфейсе.

## Подготовка (за 10 минут до показа)

1. Запустить стек и пересоздать демо-данные (см. [README](../../README.md)):
   ```bash
   docker compose up -d --build
   docker compose exec api node dist/prisma/seed/demo.js
   ```
2. Проверить `http://localhost:8080/api/health/ready` → `200`.
3. Открыть два окна браузера (второе — инкогнито): **окно A** — владелец `owner@demo-realty.example`, **окно B** — менеджер `manager1@demo-realty.example`. Пароль — `DEMO_SEED_PASSWORD` из `.env`.
4. Подготовить CSV для импорта (UTF-8, заголовки `name,phone,source,message`, 2–3 строки с вымышленными данными) — проще всего «Скачать шаблон» в диалоге импорта и заполнить его.

> Если порт 8080 занят: `WEB_PORT=8081 docker compose up -d --build` и везде использовать `:8081`.

## Ход показа

| # | Окно | Действие | Что сказать / на что обратить внимание |
|---|---|---|---|
| 1 | A | **Дашборд**: период 30 дней, KPI «Ответ вовремя», «Медиана первого ответа», «Просрочено», «Без реакции сейчас», «Забытые»; таблицы «По менеджерам» и «По источникам»; график «Лиды по дням» | Проблема клиента — заявки теряются. Видно, кто отвечает медленно и из каких каналов приходят просрочки. Время — Ташкент (UTC+5). У каждого KPI есть подсказка, как он считается |
| 2 | A | Клик по менеджеру в таблице → список лидов с фильтром | Drill-down: от метрики к конкретным заявкам |
| 3 | A | **Настройки → SLA**: показать 15 мин и рабочие часы; превью «лид в пятницу 20:00 → дедлайн …» | Ночные заявки не «горят» до начала рабочего дня. Для живой демонстрации просрочки поставить **1 мин** и сохранить |
| 4 | A | **Лиды → Новый лид**: источник Telegram, назначить `manager1`, сообщение «Здравствуйте, ищу 2-комнатную квартиру на Чиланзаре до 70 000 у.е., можно в ипотеку» | Номер лида и дедлайн SLA выставлены сервером; бейдж SLA с обратным отсчётом |
| 5 | A | **Импорт CSV** → выбрать файл → «Далее» (предпросмотр, ошибки по строкам) → «Импортировать» | Загрузка истории из Excel/CRM; ошибочные строки не ломают импорт |
| 6 | — | Подождать 1–2 минуты (планировщик проверяет каждую минуту) — тем временем показать **Настройки → API-ключи** (создание ключа, показ один раз, пример `curl` на `/intake/leads`) | Сайт или бот агентства может слать заявки напрямую |
| 7 | B | Колокольчик: уведомление о просрочке → клик → карточка лида с бейджем «Просрочено» | Менеджер и руководитель узнают о забытой заявке без ручного контроля. Раздел **«Без реакции»** — очередь просроченных |
| 8 | B | **AI-помощник → «Проанализировать»**: сводка, извлечённые бюджет/район/комнаты («Применить»), «Что уточнить у клиента», «Оценка сделки». Метка «Без AI · по правилам» | Без ключа и без согласия организации данные никуда не уходят; режим честно подписан. Переключить язык интерфейса на **UZ** и обратно — весь интерфейс двуязычный |
| 9 | B | **«Сгенерировать черновик»** (язык, тон) → отредактировать текст (метка «Изменено вами») → «Копировать» | AI ничего не отправляет сам: текст правит и отправляет человек |
| 10 | B | **«Отметить как отправленный»** → канал Telegram → «Сохранить»; затем **«Сменить статус» → «Квалифицирован»** | Первый контакт зафиксирован сервером, статус «Связались» → «Квалифицирован»; всё видно во вкладке «История» |
| 11 | A | **Лиды → «Экспорт CSV»** (с текущими фильтрами) → открыть файл в Excel | UTF-8 с BOM, даты по Ташкенту; выгрузка пишется в журнал действий |
| 12 | A | **Настройки → Журнал действий**: импорт, экспорт, смена SLA, создание ключа | Кто и что менял — для руководителя и разбора спорных случаев |
| 13 | A | **Дашборд → «Сформировать сводку»** (сводка за неделю) | Короткие выводы по метрикам для планёрки |

## Ответы на частые вопросы

- **«Как система узнаёт, что менеджер ответил?»** — в MVP менеджер отмечает первый контакт сам (ADR-017); интеграции с каналами и CRM — в roadmap.
- **«Куда уходят данные клиентов при AI?»** — по умолчанию никуда: без согласия владельца работает анализ по правилам. Включение Gemini — переключатель в «Настройки → Организация и AI» с предупреждением о передаче данных.
- **«Чужое агентство увидит наши лиды?»** — нет: изоляция по организации на сервере, покрыта автотестами.

## После показа

Вернуть SLA на 15 мин (или пересоздать демо-данные командой сида).
