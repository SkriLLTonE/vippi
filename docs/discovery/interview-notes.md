## 4. Следствия для продукта и процесса

1. **Нет доступа к отрасли** → проверка спроса должна начинаться с бесконтактного метода: аудит скорости ответа методом «тайного покупателя» силами основателя (см. [assumptions.md](./assumptions.md), раздел 3). Отчёт по конкретной компании — повод для холодного контакта. HYPOTHESIS.
2. **Демо-цель** → приоритет — сквозной сценарий без ошибок, понятный за 5 минут, с реальными (не захардкоженными) вычислениями.
3. **Нет ключа LLM** → fallback-режим — полноценный режим работы, а не заглушка: он детерминирован, протестирован и явно помечен.
4. **Холодные продажи позже** → в MVP не нужны биллинг, онбординг-воронки и маркетинговый сайт.
