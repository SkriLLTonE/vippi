## 4. Выводы для MVP

1. **Не конкурировать в оценке звонков** — STT и скоринг звонков исключены из MVP (CONFIRMED, концепция).
2. **Ключевой экран — «Без реакции»** и дашборд владельца со временем первого ответа по менеджерам и источникам; такого фокуса у перечисленных продуктов в описаниях на сайтах не найдено (HYPOTHESIS: «не найдено» ≠ «не существует»; ближайший — Reveo «судьба заявки»).
3. **Цена за компанию**, а не за место — по гипотезе ценообразования (market-research.md, раздел 10): «Контроль» 0,9–1,5 млн сум/мес, «Контроль + AI» 2–3,5 млн сум/мес. HYPOTHESIS.
4. **Интеграторы — канал, а не только конкуренты**: intake API — основа будущих вебхуков из amoCRM/Bitrix24 (ADR-004). Против Zukko (замена CRM) — аргумент «не заставляем менять CRM»; против ROPai/Reveo/nilu (звонки) — «все каналы, включая мессенджеры»; для компаний без CRM — «простой список заявок с таймером без внедрения CRM».
5. **AI-ответы клиентам — только черновик** с подтверждением человеком: категория AI-ботов коммодитизирована (Zukko, Neurobox, Lynx — от 185 000 сум/мес), а генерация на узбекском без проверки рискованна (market-research.md, 2.6).
