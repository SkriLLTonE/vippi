## 3. План проверки спроса: аудит скорости ответа («тайный покупатель»)

Цель: получить **собственные данные по Ташкенту** вместо данных РФ и одновременно создать повод для холодного контакта (у заказчика нет доступа к отрасли — CONFIRMED).

### 3.1. Выборка
- 10–20 компаний: застройщики и агентства недвижимости Ташкента. Источники: каталоги [urbo.uz](https://urbo.uz/for-new-buildings), Uysot, реклама ЖК в Instagram и Telegram-каналах (market-research.md, 9.2). PROPOSED.
- Запасная выборка: 10 автосалонов/дилеров (если по недвижимости <10 компаний с ≥2 каналами).

### 3.2. Процедура (PROPOSED)
1. На каждую компанию — до 4 обращений по разным каналам: Instagram DM, Telegram, форма на сайте, звонок. В рабочее время (пн–сб, 10:00–17:00 Asia/Tashkent), по одному обращению на канал.
2. Сценарий нейтральный: интерес к 2–3-комнатной квартире, бюджет, район. Без обещаний покупки, без повторных «атак», без сбора персональных данных сотрудников.
3. Фиксировать в таблице: время отправки, время первого ответа, наличие ответа за 1 ч / 24 ч, был ли follow-up в течение 72 ч, язык ответа (RU/UZ), уточнил ли менеджер потребность.
4. Учёт можно вести в самом Vippi Leads (импорт CSV, источник = канал) — это одновременно проверка продукта на реальном процессе (без ПДн клиентов: компании — юрлица, данные публичные).

### 3.3. Метрики и пороги
| Метрика | Порог «проблема подтверждена» (HYPOTHESIS) |
|---|---|
| Доля обращений без ответа за 1 час | ≥30% |
| Доля обращений без ответа за 24 часа | ≥15% |
| Медианное время первого ответа | >30 мин хотя бы в одном канале |
| Доля компаний без follow-up за 72 ч | ≥50% |

### 3.4. Использование результатов
- Каждой компании — персональный одностраничный отчёт («мы написали вам в Instagram в 10:14, ответ пришёл через 3 ч 20 мин») как повод для встречи с собственником. Отчёт о компании передаётся только самой компании; публично — только агрегаты без названий. PROPOSED.
- Правовые/этические ограничения: проверить у юриста допустимость (TBD), не использовать записи разговоров.

## 4. Интервью
- Цель: ≥15 интервью с собственниками/КД/РОП (критерий market-research.md, 9.5).
- Вопросы — список из market-research.md, раздел 9.3 (процессы, затраты, потери, покупка), без питча продукта. Демо показывается **после** вопросов.
- Дополнительно (для H-06, H-11): «Как бы вы сейчас посчитали долю заявок без ответа за прошлый месяц?», «Чем пользуетесь для контроля: ROPai/Reveo/интегратор/РОП вручную?».

## 5. Платный пилот
- Предложение «Аудит потерянных заявок за 90 дней + 30 дней мониторинга», 2–4 млн сум, засчитывается в подписку; гарантия возврата, если не найдено ни одной необработанной заявки (market-research.md, 9.4). HYPOTHESIS.
- В MVP аудит выполняется через импорт CSV-выгрузки из CRM клиента с колонками `receivedAt` и `firstResponseAt` (FR-061). Оплата — по счёту вне системы (платежей в MVP нет — CONFIRMED).
- Перед пилотом с реальными данными: юридическая проверка трансграничной передачи в Google Gemini (H-12, TBD-6), договор поручения обработки ПДн, решение по хостингу.
- Тип пилота определяется позиционированием (ADR-004): для компании с CRM — подключение intake API/выгрузка CSV из CRM; для компании без CRM — работа менеджеров напрямую в Vippi Leads.

## 6. Критерии решения (через 6–8 недель после демо)

Источник — market-research.md, раздел 9.5 (HYPOTHESIS, уточнить).

| Решение | Критерии |
|---|---|
| **Продолжать** | ≥15 интервью; ≥50% не знают реальной доли потерянных заявок; ≥3 оплаченных пилота из ≥10 предложений; ≥2 пилота → подписка; в данных пилотов видны потери ≥10% заявок; аудит (раздел 3) подтвердил H-01 |
| **Pivot** | Боль подтверждается, но платят только интеграторы → B2B2B через интеграторов; боль сильнее у автосалонов → смена сегмента; без интеграции ценность не видна (H-06 опровергнута) → сначала интеграция amoCRM/Telegram Business |
| **Stop** (переход к финалистам B или C из исследования) | <2 оплаченных пилотов из 10 предложений; ответы «это уже делает ROPai/интегратор/РОП»; непреодолимые правовые ограничения |
